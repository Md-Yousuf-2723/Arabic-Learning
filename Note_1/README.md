All my notes are in ==Obsidian using Excalidraw== extension. 
To see my notes, 
Download Obsidian for your Operating system

Then Install Excalidraw extension : 
- Open settings 
- Community plugin 
- Exit the restricted mode
- Then click "Browse"
- Then search "Excalidraw" 
- Click and install, then enable it. 
Then open this folder in Obsidian and all my handwritten notes will be visible.
